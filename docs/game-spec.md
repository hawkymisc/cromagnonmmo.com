# ゲームの仕様

CRO-MAGNONは約5万年前の世界を題材にしたブラウザー向け3D探索ゲームです。時代設定にはファンタジーを含みます。

## 実行と保存

- 現在はソロプレイです。タイトルのオンライン入口は無効です。
- ゲームの進行はブラウザーのWorker内で処理し、IndexedDBへ自動保存します。アカウントは不要です。
- 保存はURLのオリジンとブラウザーごとに独立します。サイトデータの削除やプライベートブラウズの終了で失われる場合があります。
- 名前・操作・音などの設定はブラウザーに保存します。音は初期状態でオフです。
- NodeのローカルサーバーとCloudflare Workerにはオンライン用の実装もありますが、現在の公開設定では使用しません。

## 世界と描画

- 世界は東西4,096 m・南北2,048 m。NOAAの地形データと海面 −68.3 mをもとに大陸と海岸線を近似しています。
- 草原・雪原・氷原・火山・砂漠を探索し、採集・狩猟・調理・道具の制作を行います。
- 人物は14種類、仲間は524・りもねこ・Dots 9種類から選択します。仲間は複数選択できます。
- 可視モデルはGLBを読み込み、LODと距離に応じた遅延読み込みを使用します。3Dモデルは参照画像とTRELLIS-2のimage-to-3Dをもとに制作しています。
- 描画は30fpsを基準とし、画質選択はありません。初期読み込みは人物と出発地点の周辺を優先します。

## 画面と操作

人物と服の色を選び、別画面で仲間を選択して開始します。洞窟では壁画を見られ、準備ができると「ゲームを始める」で入場します。人物紹介はタイトルの「関わってくれた人たち」と洞窟の「壁画の人々」にあります。

PCはキーボード・マウスとゲームパッド、スマートフォンは縦持ちのタッチ操作に対応します。プレイ画面の入力図と状況に応じた操作表示を参照してください。洞窟内では攻撃・投擲ができず、松明を手に持ちます。

## コードの構成

ゲームのルールは `shared/`、進行の調停は `application/`、実行環境との接続は `infrastructure/` と `cloudflare/`、描画とUIは `src/` にあります。詳細は [アーキテクチャ](ARCHITECTURE.md)、起動と検証は [開発環境](DEVELOPMENT.md) を参照してください。
