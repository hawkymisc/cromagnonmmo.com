# 遊び方

[公開ゲーム](https://cromagnonmmo.com/)を開き、「ソロプレイで始める」を選びます。人物・服の色を選んで「次へ」、仲間を選んで「これにする」で開始します。洞窟では壁画を見ながら読み込みを待ち、「ゲームを始める」で世界へ入ります。

## 探索

草原・雪原・氷原・火山・砂漠を歩き、石や木、食べ物を集めます。焚き火で調理し、素材を使って道具を制作できます。狩猟では相手の予備動作と体力に気を付けてください。使える行動は画面の下部に表示されます。

## 操作

- PC：キーボードとマウス、またはゲームパッドを使います。画面の入力図でキーとボタンを確認できます。
- ゲームパッド：左スティックで移動し、浅く倒すと歩き、深く倒すと走ります。右スティックで視点を動かします。
- スマートフォン：縦持ちで、左下のパッドを使って移動し、画面をなぞって見渡します。右下のボタンでジャンプ・採集・攻撃などを行います。
- メニューから持ち物・人物・服の色・仲間・音や操作の設定を変更できます。

## 仲間と壁画

仲間は複数連れていけます。小さな横送りの一覧で相手を選び、画面下部のボタンで見る・撫でるなどの行動を行います。タイトルの「関わってくれた人たち」と洞窟の「壁画の人々」では、登場する人たちを紹介しています。

## 保存

進行は同じブラウザーへ自動保存されます。タイトルへ戻るときも保存し、次回は同じURL・端末・ブラウザーで再開できます。別のURLや端末には自動で移りません。サイトデータを削除すると保存も消えるため注意してください。ソロプレイは無操作でも自動退出しません。
