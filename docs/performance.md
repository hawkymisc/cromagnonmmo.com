# 性能の確認

描画は固定30fpsを基準とし、画質の選択はありません。モデルのLODと距離に応じた読み込みで、初期読み込みと描画負荷を抑えます。

## 計測

性能を比較するときは、端末・ブラウザー・画面サイズ・人数・場所・操作・準備時間を揃えてください。フレーム間隔、CPU時間、メモリー、転送量を記録し、平均値だけでなく分布と読み込み中の挙動も確認します。

Chromeを使うゲーム操作の検証は `scripts/qa-solo-play.mjs`、本番前の一通りの検証は `pnpm run verify:production` です。実行方法は [開発環境](DEVELOPMENT.md) を参照してください。

`scripts/benchmark-terrain.mjs` は描画区画の選択と転送要求を比較する補助ツールです。GPUでの実描画や端末全体のフレームレートを保証する計測ではありません。

変更前後の同条件の計測と画面を比較し、接地・当たり判定・LOD・読み込み・入力の挙動も確認してください。実機のスマートフォン、Safari、物理ゲームパッドなどは、それぞれ実際の環境で別途検証します。
