# 主な機能と改善

- ブラウザー内で動くソロプレイと自動保存。人物・持ち物・現在地・仲間を引き継いで再開できます。
- 人物と服の色、複数の仲間を選ぶ開始画面。
- マンモス・野牛・馬の壁画が流れる読み込み画面と、人物を明るく見せる洞窟内の描画。
- PCのキーボード・マウス、ゲームパッド、スマートフォンの縦持ちタッチ操作。
- 日本語・英語の表示と、タイトル・洞窟・メニューの共有ボタン。
- 30fpsを基準とする描画、モデルのLODと遅延読み込み。
- アクセス解析は明示的な同意の後に有効になり、拒否しても遊べます。

現在の機能は [ゲーム仕様](game-spec.md)、操作と保存は [遊び方](game-guide.md) を参照してください。
