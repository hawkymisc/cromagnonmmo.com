# 家やLANでみんなで遊ぶ

同じWi-Fi・LANにいる仲間と、同じ谷で一緒に遊ぶ手順です。1台のPCがホストになり、ほかの人はスマートフォンやPCのブラウザーで参加します。インターネットに公開する機能ではありません。

## ホストのPCで起動する

Node.jsとpnpmの準備は [README](../README.md) と [開発環境](DEVELOPMENT.md) を参照してください。

```bash
pnpm install --frozen-lockfile
pnpm run start:lan
```

起動すると、ほかの機器から開くアドレスが表示されます。

```text
CRO-MAGNON running at http://localhost:3000 (local autosave every 10s)
Shared play on this network: room HOME, up to 8 people.
Open one of these on the other devices (same Wi-Fi or LAN):
  http://192.168.1.20:3000
```

ホスト自身は `http://localhost:3000` を開きます。開発中は `pnpm run dev:lan` で、変更を監視しながら同じ部屋を開けます。

## 参加する

1. ホストのゲームで、状態表示（左上の名前）から「仲間を招待する」を開きます。
2. 表示されたQRコードをスマートフォンのカメラで読み取るか、招待リンクを送ります。
3. 参加する人は「みんなで遊ぶ」から名前とキャラクターを選んで入ります。部屋のコードは最初から `HOME` です。

同じ部屋にいる人は、チャット・地図のピン・物々交換・肩車などで一緒に遊べます。待機による自動退出はありません。最大人数は既定で8人です。

## ソロのキャラクターを連れていく

ソロで集めた持ち物・道具・探索の記録を、LANの部屋のあなたに写して参加できます。ソロの保存はそのまま残ります。

- **ホストのPCで**：同じブラウザーでソロを遊んだことがあれば、参加画面の「ソロのキャラクターを連れていく」に表示されます。チェックを入れて参加します。
- **ほかの機器で**：ソロを遊んだ画面で、設定の「キャラクターを書き出す」を押してファイルを保存します。参加画面の「書き出したファイルから選ぶ」でそのファイルを選びます。cromagnonmmo.comで遊んだキャラクターも、この方法で連れていけます。

持ち込めるのは、その部屋にまだあなたの人物がいないときだけです。2回目からは、部屋に残っている人物で続きを遊びます。ホストは受け取った内容を項目ごとに確かめ、範囲外の値は丸めるか捨てます。

## 保存と再開

部屋の進行はホストのPCの `.cro-magnon-save/`（`CRO_SAVE_DIR` で変更可）に10秒ごとに保存されます。ホストを止めてもう一度 `pnpm run start:lan` を実行すると、全員が同じ持ち物と場所から再開できます。保存先を定期的に別の場所へコピーしておくと安心です。

同じブラウザーは、ホストの中で1人の人物です。部屋のコードを変えて参加すると、同じ人物が持ち物ごと別の部屋へ移ります。

## 設定

| 環境変数 | 既定 | 内容 |
| --- | --- | --- |
| `HOST` | `0.0.0.0` | 待ち受けるアドレス。特定のネットワークだけで受けるときに指定 |
| `PORT` | `3000` | ポート |
| `CRO_ROOM` | `HOME` | 参加画面に最初から入る部屋のコード（英数字・`-`・`_`、16文字まで） |
| `CRO_PLAYER_LIMIT` | `8` | 1つの部屋の最大人数（1〜64） |
| `CRO_SAVE_DIR` | `.cro-magnon-save/` | 保存先 |

PowerShellでは `$env:CRO_PLAYER_LIMIT='4'; pnpm run start:lan` のように指定します。

## つながらないとき

- **ほかの機器から開けない**：ホストと同じWi-Fiにつないでいるか確認します。ゲスト用Wi-Fiや「プライバシー分離」が有効なルーターでは、機器どうしが通信できません。
- **ファイアウォール**：Windowsでは初回起動時に「Node.js」の通信を許可するか聞かれます。プライベートネットワークで許可してください。macOSでは「受信接続を許可」します。
- **途中で切れる**：ホストのPCがスリープすると全員が切断されます。遊ぶ間はスリープしない設定にしてください。再開すると自動で再接続します。
- **スマートフォンで「ひとりで遊ぶ」が押せない**：ソロの保存は、ブラウザーが `https` か、そのPC自身（localhost）にだけ許す機能を使います。LANのアドレス（`http://192.168.…`）ではソロは遊べません。ソロは公開サイトかホストのPCで遊び、キャラクターを書き出して持ち込んでください。

## 安全について

ホストに届くのは同じネットワークの機器からの接続だけですが、その中では誰でも参加できます。信頼できる家庭や仲間内のネットワークで使い、カフェなどの公共のWi-Fiでは起動しないでください。インターネット越しの公開には、本人確認・暗号化・運用の準備が別に必要です（[マルチプレイ化の計画](multiplayer-plan.md) のPhase 2）。
